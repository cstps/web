# 시뮬레이션 영역별 그림 비교 검증

검증일: 2026-10-20

## 구현 범위

- 영역별 충족률을 배점으로 가중 평균한다.
- 영역 밖 제출 전경 비율을 추가 감점에 반영한다.
- 영역 안의 추가 도형은 양방향 비교에서 감점한다.
- 현재는 계산 모듈이며 운영 채점·교사 설정 화면에는 연결하지 않았다.

## 설정 조건

- 채점 영역은 서로 겹치지 않는 사각형 1~20개다.
- 각 영역에 정답 도형이 있어야 한다.
- 모든 정답 전경이 채점 영역에 포함돼야 한다.
- 영역별 배점 합계는 전체 배점과 같아야 한다.
- 캔버스 내부의 영역 경계에는 위치 허용 반경만큼 여백이 필요하다.
- 배점은 소수 둘째 자리까지의 문자열로 받는다.
- 흰색 배경을 제외하며 현재 색상 허용 오차는 0이다.

## 합성 이미지 검증

동일 그림, 도형 누락, 빈 제출, 색상 변경, 위치 이동,
영역 안팎 추가 도형의 비교를 확인했다.
영역 중복, 범위 초과, 배점 불일치, 정답 영역 누락,
빈 영역 및 경계 여백 부족의 차단을 확인했다.

작은 도형 누락:
전체 그림 충족률 98.039%, 영역별 충족률 70.000%.

## 실제 p5.js 렌더링 검증

초록색 원 두 개에 큰 원 70점·작은 원 30점을 설정했다.
위치 허용 반경 1픽셀, 색상 허용 오차 0을 사용했다.

| 사례 | 영역별 최종 충족률 |
|---|---:|
| 동일 그림 | 100.000% |
| 작은 원 누락 | 70.000% |
| 큰 원 누락 | 30.000% |
| 빈 제출 | 0.000% |
| 좌표 1픽셀 이동 | 99.822485% |
| 영역 밖 추가 도형 | 95.430% |
| 영역 안 추가 도형 | 98.296% |

## 원 윤곽선의 색상 차이

동일 코드 재렌더링의 픽셀 차이는 0이었다.
정답 배열을 정확히 1픽셀 이동하면 충족률은 100%였다.

p5.js에서 좌표를 옮겨 다시 그리면 작은 원의 윤곽선 2픽셀이 달랐다.
최대 색상 차이는 8이며 단색 초록 전경의 위치 차이는 없었다.
색상 허용 오차 0에서는 99.822485%가 현재 비교 규칙에 맞는 결과다.
좌표 이동만으로 항상 100%가 된다고 가정하지 않는다.
