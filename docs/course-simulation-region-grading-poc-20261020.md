# 시뮬레이션 영역별 그림 비교 검증

최초 계산 검증: 2026-10-20
운영 연결 및 화면 개선: 2026-10-21

## 구현 범위

- 영역별 충족률을 배점으로 가중 평균한다.
- 영역 밖 제출 전경 비율을 추가 감점에 반영한다.
- 영역 안의 추가 도형은 양방향 비교에서 감점한다.
- 교사용 영역 설정과 정답 버전별 저장을 연결했다.
- 학생 제출 자동 채점 및 교사 재채점에 영역별 점수 산정을 연결했다.
- 교사와 학생 화면에서 영역별 결과를 표시하고 자동 갱신한다.

## 설정 조건

- 채점 영역은 서로 겹치지 않는 사각형 1~20개다.
- 각 영역에 정답 도형이 있어야 한다.
- 모든 정답 전경이 채점 영역에 포함돼야 한다.
- 영역별 배점 합계는 전체 배점과 같아야 한다.
- 캔버스 내부의 영역 경계에는 위치 허용 반경만큼 여백이 필요하다.
- 배점은 소수 둘째 자리까지의 문자열로 받는다.
- 흰색 배경을 제외하며 현재 색상 허용 오차는 0이다.

## 합성 이미지 검증

동일 그림, 도형 누락, 빈 제출, 색상 변경, 위치 이동,
영역 안팎 추가 도형의 비교를 확인했다.
영역 중복, 범위 초과, 배점 불일치, 정답 영역 누락,
빈 영역 및 경계 여백 부족의 차단을 확인했다.

작은 도형 누락:
전체 그림 충족률 98.039%, 영역별 충족률 70.000%.

## 실제 p5.js 렌더링 검증

초록색 원 두 개에 큰 원 70점·작은 원 30점을 설정했다.
위치 허용 반경 1픽셀, 색상 허용 오차 0을 사용했다.

| 사례 | 영역별 최종 충족률 |
|---|---:|
| 동일 그림 | 100.000% |
| 작은 원 누락 | 70.000% |
| 큰 원 누락 | 30.000% |
| 빈 제출 | 0.000% |
| 좌표 1픽셀 이동 | 99.822485% |
| 영역 밖 추가 도형 | 95.430% |
| 영역 안 추가 도형 | 98.296% |

## 원 윤곽선의 색상 차이

동일 코드 재렌더링의 픽셀 차이는 0이었다.
정답 배열을 정확히 1픽셀 이동하면 충족률은 100%였다.

p5.js에서 좌표를 옮겨 다시 그리면 작은 원의 윤곽선 2픽셀이 달랐다.
최대 색상 차이는 8이며 단색 초록 전경의 위치 차이는 없었다.
색상 허용 오차 0에서는 99.822485%가 현재 비교 규칙에 맞는 결과다.
좌표 이동만으로 항상 100%가 된다고 가정하지 않는다.

## 운영 연결

- 실행 조건은 400×400, p5.js 2.3.4, 픽셀 밀도 1, 흰색 배경이다.
- 정답 저장 시 목표 이미지 생성 요청을 등록하고 상시 처리기에 알린다.
- 목표 PNG 생성 전에 정답 도형의 영역 포함 여부와 경계 여백을 검사한다.
- 검사 실패 시 PNG를 생성하지 않는다.
- 이미지 생성 결과와 영역 검사 기록은 DB에 저장한다.
- 영역별 채점 요청 등록 시 이미지 준비 상태와 검사 통과 기록을 확인한다.
- 정답 코드와 채점 설정의 해시가 검사 기록과 일치해야 한다.
- 공통 준비 상태 검사를 학생 자동 제출·교사 재채점·CLI 등록에 적용한다.
- 학생 제출이 차단되면 해당 트랜잭션을 취소하고 입력 코드를 복사할 수 있게 표시한다.
- 기존 비교 지표 전용 및 전체 그림 방식의 동작을 유지한다.

## 점수 계산

1. 각 영역의 양방향 색상 충족률을 구한다.
2. 영역별 배점 비율로 가중 평균한다.
3. 영역 밖 추가 도형에 대한 감점 비율을 적용한다.
4. 최종 충족률에 전체 배점을 곱하고 소수 둘째 자리로 반올림한다.

영역 밖 감점 반영 비율은 전체 제출 전경 중 영역 안 전경의 비율이다.
영역 안 추가 도형은 각 영역의 양방향 비교에서 감점한다.

## 교사·학생 화면

- 교사용 정답 관리에서 목표 이미지 생성·영역 검사 상태를 자동 갱신한다.
- 학생은 본인의 최근 제출 이력에서 영역별 결과를 펼쳐 볼 수 있다.
- 교사용 학생 목록에 최근 제출 시각과 최근 제출 점수를 표시한다.
- 제출 기록은 넓은 상세 창에서 회차별로 선택한다.
- 긴 제출 코드는 기본적으로 접어 두고 필요할 때 펼쳐 복사한다.
- 상세 창의 재채점 결과와 목록의 최근 제출 점수를 함께 자동 갱신한다.
- 이전 회차의 재채점으로 최근 제출 점수를 바꾸지 않는다.
- 시험용 HTML 파일은 참조가 없는 것을 확인한 뒤 삭제했다.
