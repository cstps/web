# 그림 문제은행 관리자 편집 기능

검증일: 2026-10-25

## 구현 내용

- 관리자·수업 소유자·담당교사의 문제 추가
- 관리자·소유 교사의 문제 수정
- 수정할 때 새 버전과 해당 정답 기록 추가
- 문제·버전·정답의 트랜잭션 저장
- 학생 공개와 교사 간 공유 설정 분리
- JavaScript·Python 코드용 Ace 편집기
- 로그인 사용자·편집 대상·기준 버전에 묶인 일회용 보안 토큰
- 관리자 메뉴의 그림 문제 목록·추가 연결
- 교사의 관리자 첫 화면·홈 진입 허용
- 기존 일반 문제 관리 권한 유지

## 검증 결과

- 기본 입력 검사 17개 통과
- 임시 테이블 저장 검사 18개 통과
- 전용 보안 토큰 검사 11개 통과
- 문제 1의 버전 1·2와 각각의 정답 기록 보존 확인
- 문제 목록의 추가 버튼·제목 수정 링크 확인
- 관리자 메뉴 연결·학생 진입 차단 확인

공통 csrf 입력란과의 충돌을 피하도록 전용 필드 이름을 사용한다.
오류 메시지와 토큰 변수도 공통 레이아웃 변수와 분리했다.

저장 검사는 임시 테이블의 저장·권한·버전 충돌·롤백 검증이다.
운영 테이블의 외래키·CHECK 제약 전체를 복제한 검사는 아니다.

## 후속 작업

- 영역 설정 JSON 입력을 교사용 영역·배점 표로 개선
- 문제은행 정답 그림 미리보기와 목표 이미지 검증 연결
- 문제 버전을 지정한 차시 활동 가져오기
- 공개 문제 상세·독립 실습·제출 연결
- Python 전용 운영 실행 경로 연결

Python 문제는 현재 비공개 저장만 허용한다.
문제은행 저장에는 목표 이미지 생성 요청이 아직 연결되지 않았다.

## 정답 미리보기와 편집 화면 개선

- JavaScript·Python 정답 그림 미리보기 연결
- Python 정적 미리보기를 서버와 같은 프레임 0으로 구성
- 정답 코드·언어·캔버스 설정 변경 시 재실행 안내
- 그림 문제의 저장 전 미리보기 확인 절차 추가
- 정답 코드와 미리보기의 가로 폭 균등 배치
- 미리보기 제목 오른쪽에 실행·중지 버튼 배치
- 기본 설정의 화면 너비별 다열 배치
- 문제 설명과 학생 기본 코드의 2열 배치
- 문제 설명에 로컬 TinyMCE 연결 및 저장 직전 동기화
- 기존 HTML 정제 함수를 설명 저장에 적용
- 정제 후에도 DB TEXT 크기 제한 검사

설명 HTML 정제 검사 6개를 통과했다.
화면 배치와 설명 서식 저장을 확인했다.

브라우저 미리보기와 별도로 문제은행 정답의
서버 목표 이미지 생성·검사 연결은 후속 작업이다.
