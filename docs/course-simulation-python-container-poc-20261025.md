# Python 그림 입력·컨테이너 실행 검증

검증일: 2026-10-25

## 목적

학생이 작성한 Python 그림 코드를 브라우저에서 미리 보고,
서버에서는 별도 Docker 컨테이너로 실행하는 구조를 검증한다.
기존 p5.js 실행·채점 기능은 유지한다.

## 구현 범위

- 관리자 전용 Python 코드 편집·미리보기 실험 화면
- 출처가 분리된 프레임과 Worker를 이용한 브라우저 실행
- 실행 요청의 형식·코드 크기·프레임·그림 함수 해시 검사
- 서버용 그림 함수와 컨테이너 내부 실행기
- 컨테이너 생성·상태 확인·시간 초과 종료·정리 관리
- 호스트에서 PNG 구조·CRC·압축 크기·픽셀·해시 재검사

## 서버 실행 조건

- 실행 엔진: python-stdlib-rgba-poc-v1
- 캔버스: 400×400 RGBA
- 프레임: 정수 0~600
- 코드: UTF-8 기준 최대 200,000바이트
- 로컬 이미지의 전체 SHA-256 ID를 인자로 지정
- 네트워크 차단, 루트 파일시스템 읽기 전용
- 일반 사용자 UID·GID로 실행
- Linux 권한 제거 및 추가 권한 획득 차단
- CPU 1개, 메모리 512MiB, 프로세스 128개 제한
- 임시 공간·파일 크기·로그 크기 제한
- 이번 검사의 실행 제한 시간: 8초

## 확인 결과

| 검사 | 결과 |
|---|---|
| 정적 그림 | PNG·실행 정보·기준 픽셀 일치 |
| 누적 애니메이션 | PNG·실행 정보·기준 픽셀 일치 |
| 문법 오류 | 오류 구분·PNG 미반환 |
| 실행 오류 | 오류 구분·PNG 미반환 |
| 무한 반복 | 제한 시간 후 컨테이너 직접 종료·PNG 미반환 |
| 시간 초과 후 정상 실행 | PNG·실행 정보·기준 픽셀 일치 |

각 실행 후 해당 컨테이너가 제거됐음을 확인했다.
임시 파일을 정리했으며 운영 DB·서비스는 변경하지 않았다.

## 시간 제한 처리

Docker 실행 명령을 외부 timeout으로 감싸는 초기 방식에서는
호출 프로세스의 대기가 끝나지 않는 사례가 발생했다.

실행 관리 파일에서는 컨테이너를 분리 실행하고 상태를 확인한다.
제한 시간을 넘으면 해당 이름의 컨테이너를 직접 종료한다.
결과 확인 여부와 관계없이 정리 단계에서 해당 컨테이너를 제거한다.

## 적용 범위와 남은 작업

현재 구현은 관리자용 실험이며 학생용 운영 실행·채점에는 연결하지 않았다.
PNG 검사는 파일의 구조와 실행 정보의 일관성을 확인하는 검사다.
그 자체로 제출 코드의 정답 여부를 보장하지 않는다.

제한된 Python 내장 함수 목록을 보안 경계로 취급하지 않는다.
입력 코드의 격리는 브라우저 실행 환경과 Docker에서 수행한다.

운영 연결 전 다음 항목을 별도로 검토한다.

- 출력 디렉터리 전체 용량 제한과 비정상 출력 처리
- 실행 관리 프로세스 중단 시 남은 컨테이너 회수
- 제출 렌더링과 신뢰할 수 있는 정답 비교 단계 분리
- 언어·실행 엔진·버전의 문제 설정 및 버전 고정
- Python 정적 그림의 기존 영역별 비교·점수 환산 연결
- 움직이는 그림의 지정 프레임 비교와 향후 입력 이벤트 규칙

이번 검증만으로 운영 보안 검토가 완료됐다고 판단하지 않는다.

## Python 그림의 영역별 점수 연결 검사

정답 코드와 제출 코드를 각각 별도 컨테이너에서 실행했다.
각 실행의 PNG는 호스트에서 구조·CRC·픽셀·해시를 검사했다.

별도 비교 컨테이너에는 완성된 PNG 두 장과 영역 설정,
비교 모듈만 읽기 전용으로 전달했다.
비교 컨테이너에서는 제출 코드를 실행하지 않았다.

비교 결과는 기존 PHP 영역별 결과 검증 함수를 거친 뒤
기존 점수 환산 함수로 계산했다.

큰 원 70점·작은 원 30점, 위치 허용 반경 1픽셀,
전체 배점 100.00점으로 확인했다.

| 사례 | 최종 충족률 | 점수 |
|---|---:|---:|
| 동일 그림 | 100.000% | 100.00 |
| 작은 도형 누락 | 70.000% | 70.00 |
| 빈 그림 | 0.000% | 0.00 |

검사 컨테이너와 임시 파일을 정리했다.
운영 DB·서비스 변경 없이 실험용 연결만 검증했다.
학생용 운영 채점 연결과 문제의 언어·엔진 설정은 후속 작업이다.
