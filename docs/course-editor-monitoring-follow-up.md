course_performance_dashboard.php의 학생 코드 모니터링을
코딩 실습 외 학생용 Ace 편집 화면으로 확대한다.

## 조사 및 구현 항목

- 학생이 코드를 작성하는 Ace 사용 화면을 조사한다.
- 시뮬레이션을 포함해 활동 종류별 적용 범위를 확정한다.
- 편집기 변경 이벤트를 기존 초안 저장 기능과 연결한다.
- 입력을 모아 일정 간격으로 저장해 서버 요청을 제한한다.
- 수업·활동·학생·편집 화면을 구분해 작성 중 코드를 조회한다.
- 대시보드에 마지막 저장 시각과 갱신 상태를 표시한다.
- 관리 권한이 있는 수업의 활성 수강생만 조회하도록 검사한다.
- 작성 중 코드와 정식 제출 기록을 구분한다.
- 여러 탭의 동시 편집 및 저장 충돌 처리 방식을 검토한다.

## 학생용 Ace 화면 조사 결과

조사일: 2026-10-20

- submitpage.php: 문제 풀이 코드 자동 저장이 기존에 구현돼 있다.
- 수업에 연결된 코딩 실습 초안은 기존 수업 모니터에서 조회한다.
- 수업 밖 일반 문제 풀이 초안은 현재 수업 모니터링 범위에 포함하지 않는다.

- course-simulation-reference.js: 교사용 정답 편집이므로 학생 모니터링 대상에서 제외한다.
- 이번 검색에서 확인된 학생용 Ace 화면 종류는 문제 풀이와 시뮬레이션이다.
- 향후 학생용 편집 화면을 추가할 때 활동 식별·저장·교사 조회 권한을 함께 연결한다.

## 시뮬레이션 초안 저장 충돌 방지

완료일: 2026-10-20

- 초안 revision을 문자열로 전달하고 저장 시 기준 버전을 검사한다.
- 오래된 탭의 변경으로 최신 초안을 덮어쓰는 것을 차단한다.
- 동일 코드 재전송은 기존 버전을 유지하며 성공으로 처리한다.
- 충돌 시 자동 저장을 중단하고 현재 입력 코드를 보존한다.
- 수동 저장에도 같은 버전 검사를 적용한다.
- 자동 저장 안내를 Ace 편집기 바로 아래에 표시한다.
- 정식 제출의 이벤트 재호출 순서를 보완했다.
- 임시 테이블 조건 검사와 브라우저의 충돌·저장·제출 동작을 확인했다.
