# 학생 코드 모니터링 확대 후속 작업

요청일: 2026-10-19

## 목표

course_performance_dashboard.php의 학생 코드 모니터링을
코딩 실습 외 학생용 Ace 편집 화면으로 확대한다.

## 조사 및 구현 항목

- 학생이 코드를 작성하는 Ace 사용 화면을 조사한다.
- 시뮬레이션을 포함해 활동 종류별 적용 범위를 확정한다.
- 편집기 변경 이벤트를 기존 초안 저장 기능과 연결한다.
- 입력을 모아 일정 간격으로 저장해 서버 요청을 제한한다.
- 수업·활동·학생·편집 화면을 구분해 작성 중 코드를 조회한다.
- 대시보드에 마지막 저장 시각과 갱신 상태를 표시한다.
- 관리 권한이 있는 수업의 활성 수강생만 조회하도록 검사한다.
- 작성 중 코드와 정식 제출 기록을 구분한다.
- 여러 탭의 동시 편집 및 저장 충돌 처리 방식을 검토한다.

## 진행 상태

후속 작업으로 등록했다. 아직 구현하지 않았다.
교사용 시뮬레이션 채점 결과 자동 갱신을 먼저 마무리한다.
