# 시뮬레이션 운영 점검

점검일: 2026-10-23
테스트 범위: Course 5, 시뮬레이션 활동 67

## 수행모드

- 일반 초안과 수행 시작 시각별 초안을 별도로 저장한다.
- 수행 시작 시 일반 초안을 불러오지 않는다.
- 수행 종료 후 일반 초안으로 복귀한다.
- 다른 수행의 초안과 일반 초안을 보존한다.
- 오래된 탭의 버전 충돌 시 최신 코드를 보존한다.
- 수행 기준이 변경된 이전 화면의 저장·제출을 차단한다.
- 수행 중 제출은 허용하고, 시작 시각 이후의 본인 제출 이력을 표시한다.
- 교사용 모니터링은 현재 수행 기준에 해당하는 초안을 조회한다.
- 수행 초안이 없으면 일반 초안으로 대체하지 않는다.
- 초안 저장 검사 17개와 수행 기준 요청 검사 8개를 통과했다.
- 임시 테이블 검사 후 정리했으며 해당 검사로 운영 초안을 변경하지 않았다.

관련 커밋: 78ead7d

## 학생별 채점 처리

- 제출 28: 다른 테스트 학생의 최초 제출, 채점 완료, 0.00점.
- 제출 29: 기존 테스트 학생의 제출, 채점 완료, 27.31점.
- 두 작업 모두 약 8초에 완료했고 배치 실패는 없었다.
- 두 작업의 처리 시간이 겹치지 않아 대기열 누적 처리는 미검증이다.

## 접근 권한

- 제출 30: setup 내부 무한 반복, 약 37초 후 error 상태로 종료.
- 제출 31: 후속 정상 제출, 약 8초 후 graded 상태, 100.00점.

- 해당 시점 journal 조회에는 출력이 없었으며 DB 상태로 결과를 확인했다.

## 실행 제한 설정 확인

채점 및 목표 이미지 생성 실행기의 설정에서 다음을 확인했다.

- 네트워크 차단
- CPU 1개
- 메모리 및 메모리·스왑 합계 각각 512MB
- 프로세스 수 128개 제한
- 모든 추가 capability 제거
- 권한 상승 방지
- 실행 시간 제한

설정 존재 확인과 실제 제한 동작 검증을 구분한다.
이번 점검에서 실제 확인한 제한 동작은 무한 반복의 시간 제한이다.
