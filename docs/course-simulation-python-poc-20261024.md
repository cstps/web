# Python 그림 실행 검증

기준일: 2026-10-24

## 개발 방향

- Python을 기본 학습 경로로 제공한다.
- 기존 JavaScript·p5.js 기능과 문제·학생 기록을 유지한다.
- 같은 학습 목표의 Python 문제와 JavaScript 확장 문제를 연결한다.
- 정적 그림부터 자동채점하고, 움직임·상호작용으로 확장한다.
- 실행 언어, 그림 엔진, 엔진 버전, 실행 유형과 평가 방식을 구분한다.

## 현재 구현 범위

- 표준 라이브러리 기반 실험용 RGB·알파 픽셀 그림 함수
- 원·사각형·선·색·선 두께 및 PNG 생성
- setup 초기화와 draw 프레임 순차 실행
- 관리자 전용 브라우저 실험 화면
- 로컬 Pyodide 314.0.7 및 별도 Worker
- 고정 예제 실행·중지·재실행
- 서버 기준 픽셀 SHA-256과 브라우저 결과 비교
- DB·학생 제출·공식 점수와는 미연결

프레임 0은 초기화만 수행한다.
프레임 N은 1부터 N까지 순서대로 실행한 결과다.
브라우저 표시 속도는 평가 시간의 기준으로 사용하지 않는다.

## 확인한 실행 환경

- 호스트 실험: Python 3.10.18
- 브라우저: Pyodide 314.0.7, Python 3.14.2
- Docker 검사: Python 3.12.3
- 검사 이미지: 1024kr/p5-render-poc:playwright-1.63.0

현재 이미지는 실험에 재사용했다.
운영용 Python 전용 이미지와 이미지 식별자 고정은 후속 작업이다.

## 검증 결과

- PNG 서명·청크 CRC·압축 데이터·픽셀 크기 확인
- 동일 정적 코드의 픽셀 재현 확인
- 누적 이동과 벽 반사 확인
- 브라우저 실행·중지·재실행 정상 확인
- 브라우저 애니메이션 0·1·10·40·41·120프레임의 기준 픽셀 일치
- Docker에서 정적 그림 0프레임과 애니메이션 6개 프레임의 픽셀 일치
- Docker 무한 반복 작업 시간 제한 확인
- 시간 제한 이후 정상 그림 생성 확인

위 결과는 고정 예제의 검증이며 모든 Python 코드나 도형의
버전 간 픽셀 일치를 보장하지 않는다.

## 격리 검사 조건

네트워크 차단, 읽기 전용 루트 파일시스템, 비특권 사용자,
capability 제거, 권한 상승 방지, CPU 1개,
메모리 512MB, 프로세스 128개, 임시 파일 공간과 실행 시간을 제한했다.

제한된 내장 함수 목록만으로 Python 보안을 보장하지 않는다.
현재 브라우저 Worker도 학생 코드용 보안 경계로 간주하지 않는다.
임의 코드 입력을 허용하기 전에 실행 출처와 네트워크 격리를 적용한다.

## 호스트 환경 확인 사항

호스트 Python 3.10이 Python 3.8용 Pillow 확장 모듈을 읽어
Pillow import가 실패했다.
이번 실험에서는 시스템 패키지를 변경하지 않고 표준 라이브러리를 사용했다.

## Nginx 운영 설정

/etc/nginx/mime.types에 다음 형식을 등록했다.

- mjs: application/javascript
- wasm: application/wasm

nginx -t 통과 후 reload했다.
mjs는 캐시 구분값을 붙인 조회에서도 올바른 응답을 확인했다.
이 설정 파일은 웹 저장소 밖에 있으므로 서버 이전 시 별도 반영한다.
