# 그림 문제 편집 화면 저장 방식 개선

작성일: 2026-10-27

## 저장 버튼

- 기본 정보 저장: 제목, 설명, 학생 공개, 교사 공유, 학생 코드 편집·제출 허용.
- 코드·실행·채점 설정 저장: 기본 코드, 정답 코드, 작성 언어, 문제 유형, 캔버스, 채점 설정.
- 신규 문제 등록은 전체 입력값을 함께 저장한다.

## 기본 정보 저장 동작

- 변경 없음: 버전과 변경 시각 유지.
- 공개·공유만 변경: 문제 정책만 갱신하고 버전·정답·이미지 요청 유지.
- 기본 내용 변경: 새 버전에 기존 코드·실행·채점 설정 복사.
- 기본 내용과 공개 정책을 함께 변경하면 같은 트랜잭션에서 저장.
- 기준 버전과 기존 공개 정책을 비교하여 오래된 창의 덮어쓰기 차단.
- Python 학생 공개 제한 유지.

## 미리보기

- 검사 완료된 기존 정답과 실행·채점 설정이 같으면 재실행 생략.
- 정답 코드 또는 실행·채점 설정 변경 시 미리보기 확인 요구.
- 기본 정보 저장에는 미리보기 실행을 요구하지 않음.

## 확인된 검사

임시 테이블에서 통합 저장 검사 17개 통과.

- 변경 없는 저장과 반복 저장의 기록 유지.
- 공유·학생 공개만 변경할 때 버전 유지.
- 기본 정보와 공개 정책의 동시 저장.
- 작성 중인 코드·언어·캔버스 제외 및 기존 정답·채점 설정 복사.
- 오래된 버전과 변경된 공개 정책의 덮어쓰기 차단.
- 다른 교사·학생·교사 권한 해제 계정의 변경 차단.
- 중첩 저장 차단 및 호출자 트랜잭션 유지.
- Python 학생 공개 차단 및 기본 정보 저장 시 엔진 유지.
- 이미지 요청 저장 실패 시 전체 롤백과 오류 해소 후 재저장.

임시 테이블에는 외래키·CHECK 제약을 복사하지 않았으므로
이 결과는 해당 DB 제약 자체의 검증을 포함하지 않는다.

검사 중 학생 코드 실행 및 운영 문제·제출 기록·서비스 변경 없음.

## 코드 전용 저장 추가 검사

p5.js와 Python 각각 7개, 총 14개 검사 통과.

- 코드 변경 및 새 버전 저장.
- 작성 중인 제목·설명·학생 코드 편집/제출 허용 변경 제외.
- 기존 공개·공유 정책 유지.
- 정답·렌더링·채점 설정 보존.
- 새 버전의 목표 이미지 요청 연결.
- 오래된 기준 버전 저장 차단.
- 잘못된 코드 입력 차단 및 기존 기록 유지.

통합 저장 17개와 코드 전용 저장 14개로 총 31개 검사 통과.
검사 후 임시 테이블 정리 완료.
학생 코드 실행·운영 문제·제출 기록·서비스 변경 없음.

## 구현 정리

별도 공개 정책 저장 경로는 통합 저장으로 대체하여 웹 경로에서 제거했다.
버전·정답 복사는 잠근 기존 행을 읽은 뒤 INSERT VALUES로 처리한다.
