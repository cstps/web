# 수업 Python 시뮬레이션 연결 검증

검증일: 2026-10-28

## 적용 내용

- 수업 실행 권한과 저장된 실행 설정을 검사한다.
- Python 코드는 격리 프레임과 Worker에서 미리보기로 실행한다.
- 수업 제출과 CLI 등록은 공통 채점 요청 생성 함수를 사용한다.
- 정답 버전·제출 코드·목표 PNG·실행 파일 해시를 검사한다.
- Python 실행과 PNG 비교는 기존 격리 실행 관리기를 사용한다.
- 비교 결과를 PHP에서 재검산하고 수업 채점 기록에 저장한다.
- 실행 전과 결과 저장 직전에 채점 원본을 다시 확인한다.
- 편집 화면은 Python과 p5.js에 맞는 Ace 문법 모드를 사용한다.
- Python 활동과 그림 문제의 캔버스는 400×400으로 제한한다.
- 저장된 실행 언어와 엔진은 설정 저장 요청으로 변경하지 않는다.
- 실행 기준이 달라진 이전 화면의 저장을 차단한다.
- 수업 화면과 PNG 직접 조회는 같은 목표 이미지 검사를 사용한다.
- 정답 코드와 이미지 검사 기록은 학생 응답에 포함하지 않는다.
