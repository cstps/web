# 그림 문제 목록의 개인 풀이 상태

작성일: 2026-10-27

## 표시 기준

- 맨 앞 번호 열을 제거하고 로그인 사용자에게 통과 열을 표시한다.
- 본인 제출 중 만점 기록이 있으면 초록색 체크를 표시한다.
- 제출 기록은 있지만 만점 기록이 없으면 빨간색 체크를 표시한다.
- 제출 기록이 없으면 빈칸으로 둔다.
- 비로그인 상태에서는 통과 열과 풀이 상태 안내를 숨긴다.
- 조회 실패는 별도 안내와 대시로 표시한다.

## 조회 기준

- 현재 페이지의 최대 20개 문제를 일괄 조회한다.
- 각 제출의 최신 재채점 회차를 기준으로 판정한다.
- 이전 문제 버전과 최근 10건보다 오래된 만점 기록도 반영한다.
- 후속 부분점수 제출은 다른 제출의 유효한 만점 기록을 취소하지 않는다.
- 수행모드에서는 현재 수행 기준과 시작 시각에 해당하는 기록만 반영한다.
- 수행 종료 후에는 본인 전체 기록을 다시 반영한다.
- 기존 소스 열람 권한의 수행 범위 예외를 유지한다.
- 다른 학생의 기록과 열람 권한이 없는 문제의 상태는 제공하지 않는다.
- 제출 원본 코드, 정답 코드, 내부 실행 정보는 조회하지 않는다.
- 응답에 Cache-Control: private, no-store와 Vary: Cookie를 적용한다.

## 검증 결과

- 임시 테이블을 이용한 풀이 상태 검사 36개 통과.
- 이전 버전 만점, 최신 재채점, 수행 범위 변경, 권한 검사를 확인했다.
- 잘못 저장된 점수, 잘못된 입력, 중첩 트랜잭션 차단을 확인했다.
- 검사 후 임시 테이블 정리 완료.
- 검사 과정에서 학생 코드 실행 및 운영 기록 변경 없음.
